# E-Commerce Sales Enhancement Through Data Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data to identify opportunities for improving sales performance.

The analysis focuses on products, regions, categories, discounts, order quantities, revenue, and net sales to identify strong-performing areas and areas that can be improved.

## 🎯 Objective

The main objective is to use data analysis to understand sales performance and provide data-driven recommendations for sales enhancement.

## 🛠️ Tools Used

- Google Sheets
- Pivot Tables
- Data Cleaning
- Data Analysis
- Data Visualization
- Microsoft Excel

## 📊 Analysis Performed

- Data cleaning and duplicate checking
- Gross revenue calculation
- Discount amount calculation
- Net sales calculation
- Product-wise sales analysis
- Region-wise sales analysis
- Category-wise sales analysis
- Discount vs. sales analysis
- Average Order Value analysis
- Dashboard creation

## 💡 Key Insights

The project identifies:
- Best-performing products
- Low-performing products
- Strong and weak regions
- Category performance
- Impact of discounts on sales
- Opportunities to increase average order value

## 🚀 Sales Enhancement Recommendations

Based on the analysis, recommendations are developed for:

- Product promotion
- Regional marketing
- Discount optimization
- Category-focused strategies
- Bundling and cross-selling
- Improving overall order value

## 📁 Project Files

The Excel file containing the dataset, analysis, pivot tables, and dashboard is included in this repository.
